ပါဠိ-မြန်မာ အဘိဓာန်
📖

ပါဠိစကားလုံးကို ကလစ်နှိပ်ပါ

စာဖတ်နေစဉ် မသိသော ပါဠိစကားလုံး တစ်လုံးချင်းစီကို Click နှိပ်လိုက်ရုံဖြင့် တိပိဋက ပါဠိ-မြန်မာ အဘိဓာန် အဓိပ္ပာယ် ဤနေရာတွင် ချက်ချင်း ထွက်ပေါ်လာမည် ဖြစ်ပါသည်။

ပါဝင်သော အဘိဓာန်များ -
  • တိပိဋက ပါဠိ-မြန်မာ အဘိဓာန်
  • ဦးဟုတ်စိန် ပါဠိ-မြန်မာ အဘိဓာန်
  • ဓာတွတ္ထပန်းကုံး နှင့် ပါဠိဓာတ်အဘိဓာန်
  • PTS Pali-English Dictionary
  • Concise Pali-English Dictionary

💡 ပါဠိစာလုံး (ဥပမာ- ဗုဒ္ဓ၊ နိဗ္ဗာန)၊ စာကြောင်းအတွဲလိုက် (ဥပမာ- အာသဝါ တေ ပဒါလိတာ) သို့မဟုတ် မြန်မာပြန်ခေါင်းစဉ်များ ရိုက်ထည့်၍ ရှာဖွေနိုင်ပါသည်။

ဖတ်ရှုမှုနှင့် ရှာဖွေမှု မှတ်တမ်းများ (History) မှတ်တမ်း
တိပိဋက အသုံးပြုနည်း လမ်းညွှန် (Web & Android Guide)

💻 Web Application (ကွန်ပျူတာ / Laptop / Browser) အသုံးပြုနည်း လမ်းညွှန်ချက်များ

Google Chrome, Microsoft Edge, Safari, Firefox စသည့် မည်သည့် Browser တွင်မဆို ကွန်ပျူတာ / Laptop မျက်နှာပြင်ကျယ်ကြီးများဖြင့် ပိဋကတ်တော်များကို အသေးစိတ် သုတေသနပြုခြင်း၊ ဘေးချင်းယှဉ်တွဲလေ့လာခြင်း၊ စာအုပ် Word (.docx) ထုတ်ယူခြင်း စသည့် အဆင့်မြင့်လုပ်ဆောင်ချက်များကို အပြည့်အဝ အသုံးပြုနိုင်ပါသည်။

၁ ဖတ်ရှုမှု ပုံစံ ၃ မျိုး (Reading Modes)

ကွန်ပျူတာ Header ပေါ်ရှိ ခလုတ် ၃ ခုဖြင့် မိမိနှစ်သက်ရာ ဖတ်ရှုမှုစနစ်ကို လွတ်လပ်စွာ ပြောင်းလဲနိုင်ပါသည် -

☸️
ပါဠိတော် Mode

ဆဋ္ဌသင်္ဂါယနာ မူရင်းပါဠိတော် (မူလ၊ အဋ္ဌကထာ၊ ဋီကာ) ၁၉၂ အုပ်ကို စာအုပ်အစစ်ကဲ့သို့ သန့်ရှင်းကြည်လင်စွာ သီးသန့်ဖတ်ရှုနိုင်ပါသည်။

🇲🇲
မြန်မာပြန် Mode

သာသနာရေးဦးစီးဌာနမှ ထုတ်ဝေသော တိပိဋက မြန်မာပြန် ကျမ်းစာများ (ဇာတ်တော် ၅၅၀၊ ဓမ္မပဒ၊ ဝိသုဒ္ဓိမဂ် အပါအဝင်) ၆၀ အုပ်ကို သီးသန့်ဖတ်ရှုနိုင်ပါသည်။

📖
ယှဉ်တွဲဖတ်ရှုခြင်း (Dual Split View)

ဘယ်ဘက်တွင် ပါဠိတော် နှင့် ညာဘက်တွင် မြန်မာပြန် (သို့မဟုတ် အဋ္ဌကထာ/ဋီကာ) တို့ကို ဘေးချင်းယှဉ်တွဲ၍ တစ်ပြိုင်နက် ဖတ်ရှုနိုင်ပါသည်။ ဘယ်/ညာ သီးခြားစာမျက်နှာ လှန်နိုင်သလို စာပိုဒ်နံပါတ် (Paragraph) ကို နှိပ်၍လည်း တစ်ဖက်ရှိ စာပိုဒ်သို့ တိုက်ရိုက် ခုန်ကူး highlight ပြသပေးပါသည်။

၂ ပါဠိ နှင့် မြန်မာပြန် အပြန်အလှန် ခုန်ကူးဖတ်ရှုနည်း (Smart Cross-Link)

  • ပါဠိတော် ဖတ်ရှုနေစဉ်: Header ပေါ်ရှိ 🇲🇲 မြန်မာပြန် ခလုတ်ကို နှိပ်လိုက်သည်နှင့် လက်ရှိဖတ်နေသော စာပိုဒ်နှင့် ကိုက်ညီသည့် မြန်မာပြန် စာမျက်နှာသို့ တိုက်ရိုက် ခုန်ကူးရောက်ရှိသွားပါမည်။
  • မြန်မာပြန် ဖတ်ရှုနေစဉ်: Header ပေါ်ရှိ ☸️ ပါဠိတော် ခလုတ်ကို နှိပ်လိုက်ပါကလည်း မူရင်း ပါဠိတော် စာမျက်နှာသို့ တိုက်ရိုက် ပြန်လည်ရောက်ရှိပါမည်။
  • အဋ္ဌကထာ/ဋီကာ ကူးလိုလျှင်: ဘယ်ဘက် မာတိကာ (Sidebar) မှတစ်ဆင့် ဆက်စပ် အဋ္ဌကထာ နှင့် ဋီကာ ကျမ်းစာများသို့ တိုက်ရိုက် ကူးပြောင်းနိုင်ပါသည်။

၃ လက်ဝဲဘက် မာတိကာနှင့် ကျမ်းစာရွေးချယ်မှု ဘေးဘား (Left Navigation Sidebar)

Header ရှိ ☰ ခလုတ်ကို နှိပ်၍ ဘယ်ဘက် Sidebar ကို အဖွင့်/အပိတ် ပြုလုပ်နိုင်ပြီး အောက်ပါ Tab ၅ ခု ပါဝင်ပါသည် -

  • 📑 မာတိကာ (TOC): ဝိနည်း၊ သုတ္တန်၊ အဘိဓမ္မာ နိကာယ်များနှင့် ကျမ်းစဉ်အလိုက် အခန်းကဏ္ဍပေါင်း ၁၀,၀၀၀ ကျော်ကို အပင်သစ် (Tree View) ပုံစံဖြင့် ချက်ချင်း လှန်ဖတ်နိုင်ပါသည်။
  • 📜 သုတ္တန်များ (Suttas): သုတ္တန်ပေါင်း ၆,၈၈၁ ပုဒ်ကို အက္ခရာစဉ် သို့မဟုတ် နိကာယ်အလိုက် အမြန်ရွေးချယ်နိုင်ပါသည်။
  • 🔍 အမြန်ရှာ (Quick Search): လက်ရှိကျမ်းစာအုပ်အတွင်း စာလုံးများကို အမြန်ရှာဖွေနိုင်ပါသည်။
  • 🔖 စာမှတ်များ (Bookmarks): မှတ်သားထားသော စာမျက်နှာများကို အလွယ်တကူ ပြန်လည်ကြည့်ရှုနိုင်ပါသည်။
  • 📌 စာပိုဒ်မှတ်ချက်များ (Annotations): အရောင်ခြယ်ထားသော စာပိုဒ်များနှင့် ကိုယ်ပိုင်မှတ်စုများကို စုစည်းဖတ်ရှုနိုင်ပါသည်။

၄ ကလစ်တစ်ချက်နှိပ်ရုံဖြင့် အဘိဓာန် အနက်ကြည့်ရှုနည်း (Instant Click-to-Lookup)

👆
စာလုံးကို Click နှိပ်ရုံမျှဖြင့် အနက်ထွက်ပေါ်ခြင်း:

ပါဠိစာဖတ်နေစဉ် မသိသော စကားလုံးကို Mouse ဖြင့် Click တစ်ချက် နှိပ်လိုက်ရုံဖြင့် ညာဘက်ခြမ်းရှိ အဘိဓာန်ပြားတွင် အဓိပ္ပာယ် ချက်ချင်း ထွက်ပေါ်လာမည် ဖြစ်ပါသည်။

🧠
ပါဠိ ဝိဘတ်ဖြုတ်နည်းစနစ် (Smart Pali Stemming):

ဥပမာ- ဗုဒ္ဓေါ ဟု ကလစ်နှိပ်သော်လည်း အဆုံးသတ်ဝိဘတ် -ော ကို စနစ်က အလိုအလျောက် ဖြုတ်ပေးပြီး မူရင်းပုဒ် ဗုဒ္ဓ ၏ အနက်ကို ရှာဖွေပြသပေးပါသည်။ ထို့အတူ ဓမ္မဿ၊ သမ္မာသမ္ဗုဒ္ဓဿ စသည်တို့ကိုလည်း မူရင်းပုဒ်အနက် ထွက်ပေါ်စေပါသည်။

📚
အဘိဓာန် ၈ မျိုးလုံးမှ တစ်ပြိုင်နက် ပြသခြင်း:

တိပိဋက ပါဠိ-မြန်မာ အဘိဓာန်၊ ဦးဟုတ်စိန် ပါဠိ-မြန်မာ အဘိဓာန်၊ ဓာတွတ္ထပန်းကုံး၊ ပါဠိဓာတ်အဘိဓာန်၊ PTS Pali-English စသည့် အဘိဓာန် ၈ မျိုးစလုံးမှ ဖွင့်ဆိုချက်များကို တစ်နေရာတည်းတွင် စုံလင်စွာ ဖတ်ရှုနိုင်ပါသည်။ Header ရှိ အဘိဓာန် ခလုတ်ဖြင့်လည်း အဘိဓာန်ပြားကို အဖွင့်/အပိတ် ပြုလုပ်နိုင်ပါသည်။

၅ အလွန်လျင်မြန်သော ရှာဖွေမှုစနစ် (Universal Search - Ctrl + K)

Keyboard ပေါ်မှ Ctrl + K (သို့မဟုတ် / သို့မဟုတ် Header ရှိ ရှာဖွေရန်ခလုတ်) ကို နှိပ်၍ အောက်ပါတို့ကို မီလီစက္ကန့်ပိုင်းအတွင်း ရှာဖွေနိုင်ပါသည် -

  • ပါဠိစကားလုံး (Word Index): စာလုံးပေါင်း ၉ သိန်းကျော် ကို ကြိုတင် Index ပြုလုပ်ထားသဖြင့် မျက်စိတစ်မှိတ်အတွင်း ရှာတွေ့နိုင်ပါသည်။
  • စာကြောင်း/စာပိုဒ်လိုက် (Phrase Search): ပါဠိနှင့် မြန်မာပြန် နှစ်မျိုးလုံးတွင် စကားလုံးအတွဲလိုက် (ဥပမာ- အာသဝါ တေ ပဒါလိတာ၊ သဗ္ဗေ ဓမ္မာ အနတ္တာ) ရိုက်ထည့်၍ စာကြောင်းအလိုက် တိကျစွာ ရှာဖွေနိုင်ပါသည်။
  • သုတ္တန်များ (Suttas): သုတ္တန်ပေါင်း ၆,၈၈၁ ပုဒ် ကို အမည်ဖြင့် တိုက်ရိုက် ရှာဖွေနိုင်ပါသည်။
  • ကျမ်းစာအုပ်များနှင့် မာတိကာများ: ပါဠိကျမ်းစာများနှင့် မြန်မာပြန်ကျမ်းစာများ၊ အခန်းကဏ္ဍပေါင်း ၁ သောင်းကျော် ကို ရှာဖွေနိုင်ပါသည်။

* တွေ့ရှိသည့် ရလဒ်ကို နှိပ်လိုက်သည်နှင့် သက်ဆိုင်ရာ စာမျက်နှာသို့ တိုက်ရိုက်ရောက်ရှိပြီး စာလုံးကို ဝါဝင်းတောက်ပစွာ မီးမောင်းထိုး (Highlight) ပြသပေးပါသည်။

၆ ကျမ်းစာအုပ်ကို Word ဖိုင်အဖြစ် ရယူနည်း (DOCX Download)

မာတိကာ (TOC) ရှိ ⤓ ခလုတ်ကို နှိပ်ပါ -

  • ကျမ်းစာတစ်အုပ်လုံး သို့မဟုတ် စာမျက်နှာအပိုင်းအခြား (ဥပမာ- စာမျက်နှာ ၁ မှ ၅၀) ကို ရွေးချယ်နိုင်ပါသည်။
  • Web ပေါ်တွင် မြင်တွေ့ရသည့်အတိုင်း သန့်စင်ပြီးသား စာသား (ဂါထာပုဒ်ထီး/ပုဒ်မ အပါအဝင်) ကို Microsoft Word (.docx) ဖိုင်အဖြစ် ကွန်ပျူတာထဲသို့ သိမ်းဆည်းရယူနိုင်ပါသည်။

၇ ကွန်ပျူတာ လက်ကွက်ဖြတ်လမ်းများ (Keyboard Shortcuts)

Shortcut ခလုတ် လုပ်ဆောင်ချက်
[ သို့မဟုတ် Arrow Left (◀) ယခင် စာမျက်နှာသို့ ကူးပြောင်းရန် (Previous Page)
] သို့မဟုတ် Arrow Right (▶) နောက် စာမျက်နှာသို့ ကူးပြောင်းရန် (Next Page)
Ctrl + K သို့မဟုတ် / ရှာဖွေရေး Modal ဖွင့်ရန် (Universal Search)
Ctrl + H သို့မဟုတ် H ဖတ်ရှုမှုနှင့် ရှာဖွေမှု မှတ်တမ်း ဖွင့်ရန် (History)
F11 အာရုံစူးစိုက် မျက်နှာပြင်ပြည့်မုဒ် (Focus / Fullscreen Mode)
Esc Modal များ၊ အသုံးပြုနည်း၊ အဘိဓာန် Popup ပိတ်ရန်

📱 Android Application (ဖုန်း / Tablet App) အသုံးပြုနည်း လမ်းညွှန်ချက်များ

Android ဖုန်းနှင့် Tablet များတွင် သွားရင်းလာရင်း အင်တာနက်မလိုဘဲ အချိန်မရွေး လွယ်ကူလျင်မြန်စွာ ဖတ်ရှုနိုင်ရန် လက်မတစ်ကမ်း အသုံးပြုနိုင်သော Thumb-Zone Toolbar၊ စာဖတ်ဧရိယာ ကျယ်ဝန်းစေသော Scroll Auto-Hide နှင့် ဖုန်းတွင်း 100% Offline Python Server ဖြင့် အထူးစီမံတည်ဆောက်ထားသော Application ဖြစ်ပါသည်။

၁ ပင်မ စာမျက်နှာ (Home Catalog View - APK Style)

App ဖွင့်လိုက်သည်နှင့် သန့်ရှင်းသပ်ရပ်သော ပင်မစာမျက်နှာကို မြင်တွေ့ရမည်ဖြစ်ပါသည် -

  • 📚 ပိဋကတ် သုံးပုံ ကတ်ပြားများ: သုတ်၊ ဝိနည်း၊ အဘိဓမ္မာ နှင့် အည (ဗုဒ္ဓဝင်၊ မဟာဝင်၊ ဇာတ်တော်ကြီး) တို့ကို Tab ကတ်ပြားများဖြင့် သပ်ရပ်စွာ ခွဲခြားထားပြီး မိမိဖတ်လိုသော စာအုပ်ကို တစ်ချက်နှိပ်ရုံဖြင့် ချက်ချင်း ဖတ်ရှုနိုင်ပါသည်။
  • 📖 ဆက်လက်ဖတ်ရှုရန် (Continue Reading Card): ထိပ်ဆုံးတွင် မိမိနောက်ဆုံး ဖတ်လက်စ ကျမ်းစာအမည်နှင့် စာမျက်နှာကို အဆင်သင့် ပြသပေးထားပြီး ကလစ်တစ်ချက်နှိပ်ရုံဖြင့် ရပ်နားခဲ့သည့်နေရာမှ ချက်ချင်း ဆက်လက်ဖတ်ရှုနိုင်ပါသည်။
  • 📌 ပင်မ အောက်ခြေ Navigation Bar (၆ ခု):
    🏠 ပင်မ 📖 စာဖတ် 🕒 မှတ်တမ်း 🔍 စာရှာရန် 📚 အဘိဓာန် ⚙️ အခြား

၂ မိုဘိုင်းလ် စာဖတ်မျက်နှာပြင်သစ် (Option A Modern Minimal Reader)

စာအုပ်တစ်အုပ်ကို ဖွင့်လိုက်ပါက စာဖတ်အား အနှောင့်အယှက်မဖြစ်စေသော ခေတ်မီ မိုဘိုင်းလ် စာဖတ်မျက်နှာပြင်သို့ ရောက်ရှိပါမည် -

🔝 သန့်ရှင်းသော Mobile Header
  • [←] : ပင်မ ကတ်တလောက် (Home) သို့ ပြန်သွားရန်။
  • ကျမ်းအမည် • အခန်း : နှိပ်ပါက မာတိကာ Drawer အလိုအလျောက် ပွင့်လာပါမည်။
  • [🔍] : လက်ရှိဖတ်နေသော စာအုပ်အတွင်း အမြန်ရှာဖွေရန်။
  • [☰] : ကျမ်းစာမာတိကာ ဖွင့်ရန်။
  • [စာ-နံပါတ်] Badge : နှိပ်ပါက လိုချင်သော စာမျက်နှာသို့ ခုန်ကူးရန် နံပါတ်ရိုက်ထည့်သည့် အကွက် ပွင့်လာပါမည် (မြန်မာဂဏန်း ဖြင့်လည်း ရပါသည်)။
🖐️ လက်မတစ်ကမ်း အောက်ခြေဘား (၅ ခု)
  • [🔄 ကျမ်းရွေး] : ပါဠိ ⇄ မြန်မာပြန် ⇄ အဋ္ဌကထာ ⇄ ဋီကာ စာပိုဒ်နံပါတ် (Paragraph) အလိုက် တိကျသော Two-Way Scripture Matching ဖြင့် သက်ဆိုင်ရာ စာမျက်နှာသို့ တိုက်ရိုက် ခုန်ကူးဖတ်ရှုနိုင်ပါသည်။
  • [🔍 ရှာရန်] : စာဖတ်မျက်နှာပြင်မှ မထွက်ဘဲ စာလုံး/စာကြောင်း အမြန်ရှာဖွေနိုင်ပါသည်။
  • [📖 အဘိဓာန်] : အောက်ခြေမှ အဘိဓာန်ဆွဲဖွင့်နိုင်ပါသည်။
  • [🔖 စာမှတ်] : ဖတ်လက်စ စာမျက်နှာကို ၁ ချက်နှိပ်ရုံဖြင့် စာမှတ် မှတ်သားနိုင်ပါသည်။
  • [⚙️ အပြင်အဆင်] : စာလုံးအရွယ်အစား (A- / A+), Theme (စက္ကူ/နေ့/ည), မှတ်စုဖွင့်/ပိတ်၊ စာမျက်နှာ ကော်ပီကူးယူခြင်း စသည်တို့ကို အမြန်ချိန်ညှိနိုင်ပါသည်။

၃ မျက်နှာပြင် အပြည့် စာဖတ်ရှုနိုင်မှု (Scroll Auto-Hide Chrome)

📜
စခရင်အပြည့် အနှောင့်အယှက်ကင်းစွာ ဖတ်ရှုနိုင်ခြင်း:

စာဖတ်နေစဉ် မျက်နှာပြင်ကို အောက်သို့ scroll ဆွဲချလိုက်သည်နှင့် အပေါ် Header နှင့် အောက်ခြေ Toolbar တို့သည် အလိုအလျောက် ပုန်းကွယ်သွားပြီး ဖုန်းမျက်နှာပြင် အပြည့်အဝဖြင့် စာအုပ်အစစ်ကဲ့သို့ အာရုံစိုက် ဖတ်ရှုနိုင်ပါသည်။

ခလုတ်ဘားများ ပြန်လည်အသုံးပြုလိုပါက မျက်နှာပြင်ကို အပေါ်သို့ အနည်းငယ် ပြန်ဆွဲလိုက်ရုံဖြင့် အလိုအလျောက် ပြန်လည် ပေါ်ပေါက်လာပါမည်။

၄ ဖုန်းစခရင်ပေါ်တွင် အဘိဓာန်ရှာဖွေခြင်းနှင့် မှတ်ချက်ပြုခြင်း

  • ပါဠိစကားလုံး အနက်ရှာရန်: စာဖတ်နေစဉ် မသိသော ပါဠိစာလုံးကို လက်ဖြင့် တစ်ချက်တို့ထိ (Tap) လိုက်ရုံဖြင့် အောက်ခြေတွင် အဘိဓာန် အနက်ပြား ပေါ်လာပါမည်။
  • စာသား ဖိဆွဲ မှတ်သားရန်: စာသားကို လက်ချောင်းဖြင့် ဖိဆွဲ (Long-press & drag) လိုက်ပါက ပေါ်လာသော Toolbar ဖြင့် အရောင်ခြယ်သခြင်း (🖍️)၊ ကိုယ်ပိုင်မှတ်စု ရေးသားခြင်း (📝)၊ ကူးယူခြင်း (📋) တို့ကို ပြုလုပ်နိုင်ပါသည်။

၅ အင်တာနက် လုံးဝမလိုသော Offline စနစ် (Local Python Server)

ဤ Android App သည် အင်တာနက်ဖွင့်ထားရန် မလိုဘဲ ဖုန်းထဲတွင် တိုက်ရိုက် run သော Local Server (127.0.0.1) ဖြင့် လည်ပတ်ပါသည်။ ထို့ကြောင့် တောရ၊ ရိပ်သာ၊ လိုင်းမမိသော အရပ်ဒေသများတွင်ပင် ပိဋကတ်တော် ကျမ်းစာအားလုံးနှင့် အဘိဓာန် ၈ မျိုးလုံးကို မြန်ဆန်စွာ အပြည့်အဝ အသုံးပြုနိုင်ပါသည်။

၆ အက်ပ်အတွင်း အလိုအလျောက် ဗားရှင်းမြှင့်တင်ခြင်း (In-App Auto-Updater)

GitHub Releases တွင် Android Version အသစ် (APK) ထွက်ရှိတိုင်း -

  • အင်တာနက်ဖွင့်၍ App ကို ဖွင့်လိုက်ပါက Version အသစ်ရှိကြောင်း Update Dialog အလိုအလျောက် သတိပေးပါမည်။
  • ဒေါင်းလုဒ် ခလုတ်ကို နှိပ်လိုက်ရုံဖြင့် APK အသစ်ကို တိုက်ရိုက်ဒေါင်းလုဒ်ရယူပြီး Install ပြုလုပ်နိုင်ပါသည်။
  • ပင်မ အောက်ခြေ [⚙️ အခြား] menu သို့မဟုတ် အောက်ခြေရှိ အပ်ဒိတ် စစ်ဆေးရန် ခလုတ်ကို နှိပ်၍လည်း အချိန်မရွေး ကိုယ်တိုင် စစ်ဆေးနိုင်ပါသည်။

၁ ဖုန်းနှင့် ကွန်ပျူတာ အချင်းချင်း Sync ချိတ်ဆက်နည်း (Cross-Device Cloud Sync)

သင်၏ ဖုန်းနှင့် ကွန်ပျူတာတို့တွင် မှတ်ချက်များ၊ Bookmark များနှင့် ဖတ်ရှုမှုမှတ်တမ်းများကို တူညီစွာ ရရှိစေရန် အောက်ပါအတိုင်း ချိတ်ဆက်နိုင်ပါသည် -

  • ဘေးဘား (Sidebar) ရှိ 📌 စာပိုဒ်မှတ်ချက်များ tab ထဲမှ ☁️ ခလုတ်ကို နှိပ်ပါ။
  • ပထမဆုံး စက် တွင် 🔑 ကုဒ်အသစ် ထုတ်ရန် ကို နှိပ်ပါ — XXXX-XXXX ပုံစံ ကုဒ်တစ်ခု ရလာပါမည်။
  • နောက်စက်များ (ဖုန်း သို့မဟုတ် ကွန်ပျူတာ) တွင် ထိုကုဒ်ကို ရိုက်ထည့်ပြီး ချိတ်မည် ကို နှိပ်ပါ။
  • ချိတ်ဆက်ပြီးပါက စက်အားလုံးတွင် မှတ်တမ်းနှင့် မှတ်ချက်များ အလိုအလျောက် တပြေးညီ ရရှိနေမည် ဖြစ်ပါသည်။

၂ မှတ်တမ်း သိမ်းဆည်းခြင်းနှင့် စာရင်းအင်း (Backup / Restore & Insights)

💾 Backup & Restore

မိမိမှတ်သားထားသော Bookmark၊ စာပိုဒ်မှတ်ချက်များနှင့် ဆက်တင်များကို JSON ဖိုင်ဖြင့် ကွန်ပျူတာ/ဖုန်းထဲသို့ သိမ်းဆည်းထားနိုင်ပြီး၊ အချိန်မရွေး ပြန်လည်တင်သွင်း (Restore) နိုင်ပါသည်။

📊 ဖတ်ရှုမှု စာရင်းအင်း (Insights)

မိမိ နေ့စဉ်၊ အပတ်စဉ် ဖတ်ရှုခဲ့သော စာမျက်နှာအရေအတွက်၊ အများဆုံးလေ့လာခဲ့သည့် နိကာယ်များနှင့် ပိဋကတ်စာရင်းအင်းများကို ဇယားများဖြင့် လေ့လာကြည့်ရှုနိုင်ပါသည်။

၃ ဆဋ္ဌသင်္ဂါယနာ မူရင်း သန့်စင်မှု ဂုဏ်ပုဒ်များ (Chatthasangayana Typography)

  • ဆဋ္ဌမူ ဂါထာ ပုဒ်ထီး (၊) ပုဒ်မ (။) စနစ်: ဆဋ္ဌမူ စာအုပ်ကြီးများအတိုင်း ဝါကျပိုင်း အနက်ရပ်နားမှု ပုဒ်ထီး (၊) နှင့် ဝါကျအဆုံး ပုဒ်မ (။) များကို တိကျစွာ ထိန်းသိမ်းထားပါသည်။
  • ပုံနှိပ်တွဲ အမှတ်အသား (Printed Volume Label): အတွဲများသော နိကာယ်များ (အံ၊ ပတွဲ / သံ၊ ဒုတွဲ စသည်) တွင် စာအုပ်နာမည်ဘေး၌ ပုံနှိပ်တွဲ အမှတ်အသားကို ပြသပေးထားသဖြင့် ပြင်ပစာအုပ်အစစ်နှင့် ယှဉ်ဖတ်ရာတွင် လွယ်ကူစေပါသည်။
  • သဒ္ဒါအလိုက် စာခေါက်စနစ် (Smart Line Breaking): ပါဠိစာလုံးရှည်ကြီးများကို သဒ္ဒါအရ သဘာဝကျသော နေရာမှသာ စာကြောင်းခေါက်ဆင်းစေပြီး စာလုံးဆင့်များ မကွဲထွက်စေရန် စီမံထားပါသည်။

၄ 🙏 မူရင်းဖန်တီးသူအား အသိအမှတ်ပြုခြင်း၊ ကျေးဇူးတင်လွှာ နှင့် ခွင့်တောင်းစာ (Credits & Dedication)

* ဤအရှင်မြတ် (Pn Daza) သည် အခု အသုံးပြုထားသော App နှစ်ခုအပြင် တခြား ဘုရားဟော ပိဋကတ်ကျမ်းစာဆိုင်ရာ သာသနာအတွက် အလွန်အကျိုးများသော Applications များစွာကို ရေးသားပြုစုထားပြီး၊ ပိဋကတ်ကျမ်းစာ လေ့လာသူတိုင်း အားကိုးအားထား ပြုရသည့် Apps များစွာဖြင့် သာသနာတော်ကို အကျိုးပြုခဲ့သော အရှင်မြတ် ဖြစ်ပါသည်။ မူရင်း App ရေးသားသူ Pn Daza ၏ တည်ဆောက်ခဲ့သော ကြိုးစားအားထုတ်မှုနှင့် ဉာဏ်ပညာအား လေးစားကြည်ညိုစွာဖြင့် မှတ်တမ်းတင် ဂုဏ်ပြုအပ်ပါသည်။ အခုလို (မိမိလိုအပ်ချက်အတွက်) ပြင်ဆင် အသုံးပြုတာကိုလည်း ခွင့်ပြုပေးဖို့အတွက် မူရင်းဖန်တီးသူ အရှင်မြတ်အား လေးစားစွာဖြင့် ခွင့်ပြုပေးပါရန် တောင်းပန်အပ်ပါသည်။
